# Screenshot capture notes

The neutral public-page background is from a Chrome capture of
https://example.com/ made October 17, 2026. On November 1, the SiteClock timer
overlay was replaced with the current on-page timer screenshot supplied by the
owner, then composited into the same lower-right position for this store image.

- `01-on-page-timer-1280x800.png`: 1280 × 800 browser viewport capture.
- `02-on-page-timer-640x400.png`: compact viewport capture, with the timer more
  legible at the store's smaller display size. Chrome returned a 625 × 391 image,
  which was resized to the required 640 × 400 export dimensions.

The 1280 × 800 composition was exported as PNG; the compact image is a resized
copy for the store's smaller display size. The overlay's text and displayed total
come directly from the supplied SiteClock screenshot.

The overlay displays the owner-supplied example total of 3h 2m 46s. No real
account details or private browsing history are included. Both screenshots show
the same feature; use the 1280 × 800 image for store submission.

The promotional tiles in `../assets/` are original vector artwork. The store
screenshot is a documented composition of a neutral public page and the supplied
extension UI.
