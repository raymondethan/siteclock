# Screenshot capture notes

Captured October 17, 2026, from the installed SiteClock extension in Chrome on
the neutral public page https://example.com/.

- `01-on-page-timer-1280x800.png`: 1280 × 800 browser viewport capture.
- `02-on-page-timer-640x400.png`: compact viewport capture, with the timer more
  legible at the store's smaller display size. Chrome returned a 625 × 391 image,
  which was resized to the required 640 × 400 export dimensions.

The browser tool returned JPEG-encoded bytes; both exports were converted to PNG.
Only format conversion and the compact image's small size adjustment were made.

The timer is paused at zero on this newly opened hostname because Chrome was
not the foreground app during capture. The extension UI and website content
were not fabricated or replaced. No timer totals were seeded or edited, and no
private browsing history, browser tab strip, bookmarks, or account details are
included. Both screenshots show the same feature; use the compact capture if
only one screenshot is wanted.

The promotional tiles in `../assets/` are original vector artwork, not browser
screenshots. Their text describes existing functionality. The review gallery
clearly separates the two kinds of images.
