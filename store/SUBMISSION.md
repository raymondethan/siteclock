## Dashboard

Open https://chrome.google.com/webstore/devconsole in your own Chrome window.
Complete developer registration if prompted, including Google's agreement,
registration fee, verified contact email, and two-step verification requirements.

When the dashboard is available:

1. Choose **Add new item** and upload `dist/siteclock-0.1.0.zip`.
2. Enter the copy from `store/listing.md`.
3. Upload `icons/icon-128.png`, `store/assets/promo-small-440x280.png`, and a
   screenshot from `store/screenshots/`. The marquee image is optional.
4. Enter permission explanations and data-handling disclosures from
   `store/privacy-practices.md`.
5. Set the privacy-policy URL to
   https://github.com/raymondethan/siteclock/blob/master/PRIVACY.md.
6. Choose public distribution and complete Google's required publisher fields.
   Do not invent business/trader declarations; answer them for the publisher's
   actual circumstances.
7. Add review testing instructions from `store/listing.md`.
8. Submit for review with automatic publication after approval, as requested.

No request for additional product features is part of this release. Keep the
current unpacked installation until existing totals can be transferred safely;
the store copy may have a different extension ID and separate local storage.
